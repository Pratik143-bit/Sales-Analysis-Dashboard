#  Sales Analysis Dashboard

##  Project Overview

This project is an interactive **Sales Analysis Dashboard** built using **Microsoft Power BI**. It provides a comprehensive overview of sales performance, profit, quantity sold, discounts, product performance, regional sales distribution, and monthly sales trends. The dashboard enables users to monitor key business metrics and make data-driven decisions.

---

##  Objectives

* Analyze overall sales performance.
* Track profit, quantity sold, and discounts.
* Compare revenue across product categories.
* Identify monthly sales trends.
* Analyze top-performing products.
* Understand regional sales distribution.
* Enable interactive filtering for better insights.

---

## Tools & Technologies

* DAX (Data Analysis Expressions)
* Data Modeling

## Key Insights

* Technology category generates the highest revenue.
* Sales show fluctuations throughout the year with higher sales towards the end of the year.
* Sales are distributed across four regions (West, East, Central, and South).
* KPI cards provide a quick summary of business performance.
* Interactive filters allow users to analyze sales from different perspectives.
